# Piece images

licensed [GPLv2+](https://www.gnu.org/licenses/gpl-2.0.txt), copied unchanged from
[lichess-org/lila](https://github.com/lichess-org/lila/tree/master/public/piece/cburnett)
(`public/piece/cburnett`; credits in lila's `COPYING.md`). `scripts/build_viewer.py` inlines them
into `viewer/gotham.html`.
